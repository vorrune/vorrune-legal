Privacy Policy — VORRUNE Uploader

Last updated: October 11, 2026

1. Overview

VORRUNE Uploader ("the App") is a private tool used only by the creator of the VORRUNE channel ("the Operator") to send the Operator's own short videos to the Operator's own TikTok account as drafts.

2. Information we receive from TikTok

  • OAuth access token and refresh token
  • open_id (an identifier of the authorized TikTok account)
  • The list of authorized scopes (user.info.basic, video.upload)
  • Upload status returned by the API (e.g. publish_id, processing status)

The App does not collect followers, messages, contacts, viewing history, or any information about other TikTok users.

3. How the information is used

The information is used only to upload videos to the authorized account's TikTok inbox and to check whether each upload has completed. It is not used for advertising, profiling, or analytics.

4. Storage and sharing

Tokens are stored locally on the Operator's own computer and are never sent to any server other than TikTok's API. No information is sold, rented, or shared with third parties.

5. Retention and deletion

Tokens are kept only while the connection is active. Revoking access from the TikTok app (Settings and privacy → Security → Apps and services) invalidates them, and the Operator deletes the local token file when the App is no longer used.

6. Children

The App is not directed to children and is used only by the adult Operator.

7. Changes

This policy may be updated. The latest version is always available at this URL.

プライバシーポリシー — VORRUNE Uploader

最終更新日: 2026年10月11日

1. 概要

VORRUNE Uploader（以下「本アプリ」）は、VORRUNE チャンネルの運営者（以下「運営者」）だけが使う個人用ツールです。運営者自身のショート動画を、運営者自身の TikTok アカウントへ下書きとして送信します。

2. TikTok から受け取る情報

  • OAuth アクセストークンとリフレッシュトークン
  • open_id（認証した TikTok アカウントの識別子）
  • 許可されたスコープ（user.info.basic, video.upload）
  • API が返すアップロードの状態（publish_id、処理状況など）

フォロワー、メッセージ、連絡先、視聴履歴、他の TikTok ユーザーの情報は取得しません。

3. 利用目的

認証したアカウントの TikTok 受信箱へ動画を送ること、および送信の完了を確認することだけに使います。広告、プロファイリング、分析には使いません。

4. 保管と共有

トークンは運営者自身の PC にだけ保存し、TikTok の API 以外のサーバーへは送りません。第三者への販売・貸与・共有はしません。

5. 保存期間と削除

トークンは連携が有効な間だけ保持します。TikTok アプリの「設定とプライバシー → セキュリティ → アプリとサービス」で連携を解除するとトークンは無効になります。本アプリを使わなくなったときは、運営者がローカルのトークンファイルを削除します。

6. 子ども

本アプリは子ども向けではなく、成人の運営者だけが使います。

7. 変更

本ポリシーは変更することがあります。最新版は常にこの URL で公開します。
