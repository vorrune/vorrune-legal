VORRUNE Uploader

VORRUNE Uploader is a desktop tool used by the creator of the VORRUNE short-film channel. It sends finished vertical videos to the creator's own TikTok account as drafts through the TikTok Content Posting API (upload to inbox). The creator then reviews the draft, writes the caption and publishes it manually in the TikTok app.

How it works

  1. The creator signs in with TikTok (Login Kit) and grants video.upload.
  2. The tool uploads a finished video file to the creator's TikTok inbox.
  3. The creator opens the draft in TikTok, edits it, chooses the privacy setting and posts it.

The tool never posts publicly by itself and does not read any other data from TikTok.
